# DBMS and SQL

## 1. Database Management System (DBMS)

- **DBMS:** Database Management System.
- Software used for managing databases.
- **RDBMS:** Relational Database Management System.
- Uses the relational model.
- Examples: MySQL, Oracle.
- **MS Access:** Database management tool used for small business databases.

## 2. SQL

- **Full Form:** Structured Query Language.
- Used for database management.
- It is a non-procedural/declarative language.
- Inventors: Donald Chamberlin and Raymond Boyce.
- Year: 1974.

## 3. Important Abbreviations

| Term | Full Form |
|---|---|
| DBMS | Database Management System |
| RDBMS | Relational Database Management System |
| SQL | Structured Query Language |
