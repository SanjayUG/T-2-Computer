# MS PowerPoint

Microsoft PowerPoint is a presentation software developed by Microsoft. It is used to create slideshows, business presentations, educational content and reports.

- **Introduced:** 1987 (by Forethought Inc., acquired by Microsoft).
- **File Extensions:** `.ppt` (older versions), `.pptx` (latest versions).
- **Purpose:** Visual communication using text, images, charts, audio and video.

## Basic Components

| Component | Function |
|---|---|
| Slide | Single page of a presentation. |
| Slide Deck | Complete collection of slides. |
| Slide Layout | Predefined structure of a slide. |
| Slide Master | Controls overall design, fonts, colours and backgrounds. |
| Placeholder | Pre-formatted box for inserting content. |
| Slide Sorter View | Displays slides as thumbnails for reordering. |
| Notes Pane | Area for speaker notes. |
| Transitions | Visual effects between slides. |
| Animations | Effects applied to objects within slides. |

## Important Tabs

| Tab | Main Purpose |
|---|---|
| Home | Basic editing and formatting. |
| Insert | Add tables, pictures, shapes, charts, audio and video. |
| Design | Themes, variants, slide size and background. |
| Transitions | Effects between slides (Fade, Wipe, Push). |
| Animations | Effects on slide objects (Entrance, Emphasis, Exit). |
| Slide Show | Present slides and use Presenter View. |
| Review | Spelling, comments, language and protection. |
| View | Normal, Outline, Slide Sorter, Slide Master and Zoom. |
