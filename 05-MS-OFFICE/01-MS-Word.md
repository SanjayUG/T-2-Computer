# MS Word

Microsoft Word is a word processing software developed by Microsoft. It is part of the MS Office Suite and is used to create, edit, format, and print documents.

## Interface Components

| Component | Function |
|---|---|
| Title Bar | Displays document and program name. |
| Quick Access Toolbar | Save, Undo, Redo. |
| Ribbon | Contains tabs and commands. |
| Workspace | Area where text is typed. |
| Ruler | Helps with alignment, indentation and margins. |
| Status Bar | Shows page number, word count and language. |
| Scroll Bars | Navigate the document. |
| Zoom Control | Adjusts document view size. |

## Important Tabs

| Tab | Main Purpose |
|---|---|
| Home | Text formatting and editing. |
| Insert | Add tables, pictures, shapes, links and symbols. |
| Design | Themes, colours, fonts and page background. |
| Layout | Margins, orientation, size and columns. |
| References | Table of contents, footnotes and citations. |
| Mailings | Mail Merge, envelopes and labels. |
| Review | Spelling, grammar, comments and Track Changes. |
| View | Document views, ruler, zoom and macros. |
