# MS Excel

Microsoft Excel is a spreadsheet software developed by Microsoft. It is part of the MS Office Suite and is used for data entry, analysis, calculations, charts and financial reports.

- **Introduced:** 1985 (Apple), 1987 (Windows).
- **File Extensions:** `.xls` (old versions), `.xlsx` (new versions).

## Basic Elements

| Element | Function |
|---|---|
| Workbook | Main Excel file containing multiple worksheets. |
| Worksheet | A single sheet in a workbook. |
| Rows | Horizontal lines, numbered 1, 2, 3… |
| Columns | Vertical lines, labelled A, B, C… |
| Cell | Intersection of a row and column (e.g., A1). |
| Cell Address | Unique reference of a cell (e.g., C5). |
| Active Cell | Currently selected cell. |
| Formula Bar | Displays or edits formulas and cell data. |
| Name Box | Shows the address of the active cell. |
| Range | Group of cells (e.g., A1:C5). |
| Pivot Table | Summarises and analyses large datasets. |
| Charts | Graphical representation of data. |

## Important Tabs

| Tab | Main Purpose |
|---|---|
| Home | Basic editing and formatting. |
| Insert | Tables, pictures, charts and illustrations. |
| Page Layout | Page setup and printing. |
| Formulas | Insert and manage formulas. |
| Data | Manage, sort and analyse data. |
| Review | Proofing, comments and protection. |
| View | Adjust worksheet view and zoom. |

## Formulas & Functions

- A formula is an expression used to calculate values.
- Every formula starts with `=`.
- Example: `=A1+B1`

| Function | Syntax | Use |
|---|---|---|
| SUM | `=SUM(A1:A10)` | Adds values. |
| AVERAGE | `=AVERAGE(A1:A10)` | Finds average. |
| MIN | `=MIN(A1:A10)` | Smallest value. |
| MAX | `=MAX(A1:A10)` | Largest value. |
| COUNT | `=COUNT(A1:A10)` | Counts numeric entries. |
| COUNTA | `=COUNTA(A1:A10)` | Counts non-empty cells. |
| ROUND | `=ROUND(A1,2)` | Rounds a value. |
