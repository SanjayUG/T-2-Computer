# Logic Gates

Logic gates are basic building blocks of digital circuits. They take binary inputs (0 or 1) and produce a binary output.

| Gate | Symbol | Operation |
|---|---|---|
| AND | ∧ | Output 1 only if all inputs are 1 |
| OR | ∨ | Output 1 if any input is 1 |
| NOT | ¬ | Inverts the input |
| NAND | ¬(A∧B) | Inverse of AND |
| NOR | ¬(A∨B) | Inverse of OR |
| XOR | ⊕ | Output 1 when inputs differ |
| XNOR | ⊙ | Output 1 when inputs are same |

**Truth Table**
