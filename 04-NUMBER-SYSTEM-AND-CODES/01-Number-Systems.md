# Number Systems

A number system represents numbers using specific digits.

| System | Base | Digits | Example |
|---|---:|---|---|
| Decimal | 10 | 0–9 | 145 |
| Binary | 2 | 0, 1 | 1010 |
| Octal | 8 | 0–7 | 725 |
| Hexadecimal | 16 | 0–9, A–F | 2A |

### Important Conversions
- Binary `1010` = Decimal `10`
- Octal `725` = Decimal `469`
- Hexadecimal `2A` = Decimal `42`
