# Computer Languages

A computer language is used to write programs that instruct a computer.

### Types of Languages

| Type | Description | Examples |
|---|---|---|
| Machine Language (1GL) | Binary code; directly understood by CPU | 0s and 1s |
| Assembly Language (2GL) | Uses mnemonics; requires assembler | MOV, ADD, SUB |
| High-Level Language | English-like syntax; requires compiler/interpreter | C, FORTRAN, COBOL, BASIC |
| 4GL | Very high-level; reduces coding effort | SQL, MATLAB |
| 5GL | AI and logic-based problem solving | Prolog, Mercury |
