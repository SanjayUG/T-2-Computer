# Computer Codes

Codes represent characters, numbers and symbols in binary form.

| Code | Full Form | Key Point |
|---|---|---|
| BCD | Binary Coded Decimal | 4 bits per digit |
| EBCDIC | Extended Binary Coded Decimal Interchange Code | 8 bits; IBM |
| ASCII | American Standard Code for Information Interchange | 7-bit / 8-bit |
| Unicode | Universal Code | Supports world languages and emojis |
| Gray Code | — | Only one bit changes at a time |
| ISCII | Indian Script Code for Information Interchange | 8 bits; Indian languages |

**Source:** `Computer_Notes(MM).pdf`
