# Computer Software

Software is a set of programs, procedures and data that tells a computer how to perform tasks. It is intangible.

## Classification of Software

### 1. System Software

Controls hardware and provides a platform for application software.

| Type | Function | Examples |
|---|---|---|
| Operating System | Manages hardware and software | Windows, Linux, Android |
| Utility Programs | Maintenance tasks | Antivirus, WinRAR, Disk Cleanup |
| Device Drivers | Connect OS with hardware | Printer, Graphics Driver |

### 2. Application Software

Designed to perform user-specific tasks.

| Type | Function | Examples |
|---|---|---|
| General Purpose | Common tasks | MS Office, VLC, Browsers |
| Special Purpose | Specific tasks | Tally, AutoCAD |
| Customized | Organization-specific | Banking software, Railway Reservation |

### 3. Programming Software

Used to write, test and debug programs.

| Tool | Function |
|---|---|
| Compiler | Converts the entire HLL program into machine code |
| Interpreter | Converts code line by line |
| Assembler | Converts assembly language into machine code |
| IDE | Combines editor, compiler and debugger |

## Software Categories by Usage

| Category | Meaning | Examples |
|---|---|---|
| Freeware | Free to use; cannot modify | Adobe Acrobat Reader |
| Shareware | Free trial, then paid | WinZip |
| Open Source | Source code available for modification | Linux, Python |
| Proprietary | Company-owned, licensed software | Windows, MS Office |
| Firmware | Software stored in ROM to control hardware | BIOS |
