# Operating Systems

An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages resources and provides services to applications.

## Functions of Operating System

- **Process Management:** Schedules program execution.
- **Memory Management:** Allocates and deallocates memory.
- **File Management:** Stores, retrieves and organizes data.
- **Device Management:** Controls I/O devices through drivers.
- **Security:** Protects data and resources.
- **User Interface:** Provides CLI or GUI.
- **Networking:** Supports communication between systems.

## Types of Operating Systems

| Type | Function | Examples |
|---|---|---|
| Batch OS | Executes jobs in batches without user interaction | Early IBM systems |
| Multiprogramming OS | Runs multiple programs through CPU time-sharing | UNIX |
| Multitasking OS | Runs multiple tasks | Windows, macOS |
| Time-Sharing OS | Gives each user a CPU time slice | Mainframes, UNIX |
| Distributed OS | Manages multiple computers as one system | Amoeba, LOCUS |
| Real-Time OS (RTOS) | Provides immediate response | VxWorks, QNX |
| Mobile OS | Designed for smartphones/tablets | Android, iOS |
