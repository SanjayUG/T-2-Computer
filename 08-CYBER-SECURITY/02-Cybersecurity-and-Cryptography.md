# Cybersecurity and Cryptography

## Cryptography

**Cryptography** is the science of securing communication by converting information into an unreadable format (encryption) and converting it back (decryption) using keys.

**It ensures:**
- **Confidentiality** – Protects information from unauthorized access.
- **Integrity** – Ensures data remains accurate.
- **Authentication** – Verifies the identity of the sender.
- **Non-repudiation** – Prevents denial of an action or communication.

## Types of Cryptography

| Type | Description | Examples / Key Points |
|---|---|---|
| Symmetric Key | Same key for encryption and decryption. | Fast; key distribution is difficult. DES, AES, Blowfish |
| Asymmetric Key | Uses Public Key and Private Key. | Secure key exchange; slower. RSA, ECC |
| Hash Functions | One-way; no decryption possible. | Password storage, digital signatures. MD5, SHA-1, SHA-256 |
| Hybrid Cryptography | Combines symmetric and asymmetric methods. | SSL/TLS (HTTPS) |
| Quantum Cryptography | Uses principles of quantum mechanics. | Quantum Key Distribution (QKD) |

## Applications of Cryptography

- **Data Security:** Protects sensitive data.
- **Digital Signatures:** Ensures authenticity of sender.
- **Online Banking & E-Commerce:** Secures transactions.
- **Email Encryption:** Protects communication.
- **Blockchain & Cryptocurrencies:** Uses cryptographic hashing.
