# Email and Internet Protocols

## 1. Email

Email (Electronic Mail) is a method of exchanging digital messages over the Internet.

- Works on the **Client-Server Model**.
- Uses SMTP for sending and POP3/IMAP for receiving.
- Requires a unique email address.

## 2. Structure of an Email

| Part | Function |
|---|---|
| To | Main recipient |
| CC (Carbon Copy) | Visible secondary recipients |
| BCC (Blind Carbon Copy) | Hidden recipients |
| Subject | Topic or heading |
| Body | Main message |
| Attachments | Added files such as PDFs and images |
| Signature | Sender's contact information |

## 3. Email Functions

| Function | Meaning |
|---|---|
| Reply | Respond to the sender |
| Reply All | Respond to sender and all recipients |
| Forward | Send received mail to another person |
| Attach | Add files to an email |
| CC/BCC | Add visible/hidden recipients |

## 4. Email Folders and Features

| Feature | Purpose |
|---|---|
| Inbox | Stores received emails |
| Outbox/Sent | Stores sent emails |
| Drafts | Stores unsent emails |
| Spam/Junk | Stores unwanted emails |
| Trash/Deleted | Stores deleted emails temporarily |
| Archive | Stores old emails without deleting |
| Attachments | Adds documents, PDFs and images |
| Signature | Automatically adds sender information |
| Search | Finds specific emails |

## 5. Internet Protocols

| Protocol | Port | Use |
|---|---:|---|
| HTTP | 80 | Transfers web pages |
| HTTPS | 443 | Secure web browsing |
| FTP | 20/21 | File transfer |
| SMTP | 25 | Sending emails |
| POP3 | 110 | Receiving emails; downloads and removes from server |
| IMAP | 143 | Receiving and managing emails; keeps on server |
| DNS | 53 | Converts domain names ↔ IP addresses |
| SSH | 22 | Secure remote login |
| Telnet | 23 | Remote login (not secure) |

## 6. Important Points

- **SMTP** → Sending emails.
- **POP3** → Receiving emails; downloads and removes them from the server.
- **IMAP** → Receiving and managing emails; keeps them on the server.
- **HTTPS** → Secure version of HTTP.
- **DNS** → Converts domain names into IP addresses.
- **FTP** → Transfers files between computers.
