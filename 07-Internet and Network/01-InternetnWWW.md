# Internet and World Wide Web (WWW)

## 1. Internet

- Global network of interconnected computers.
- Also called a **Network of Networks**.
- Uses standardized protocols to share information and resources.
- Based on the **Client-Server Model**.

## 2. History of Internet

| Year | Event |
|---|---|
| 1969 | ARPANET started in USA |
| 1971 | First email sent by Ray Tomlinson |
| 1983 | TCP/IP adopted as standard protocol |
| 1989 | WWW invented by Tim Berners-Lee |
| 1995 | Internet commercialized |
| 2004 onwards | Web 2.0 — interactive web |

## 3. World Wide Web (WWW)

- **Full Form:** World Wide Web.
- Collection of linked hypertext documents.
- Invented by **Tim Berners-Lee (1989)**.

## 4. Web Browser

- Application software used to access and view websites.
- Retrieves web pages through HTTP/HTTPS.
- Renders HTML, CSS and JavaScript.

| Browser | Year | Developer |
|---|---:|---|
| Google Chrome | 2008 | Google |
| Mozilla Firefox | 2002 | Mozilla Foundation |
| Microsoft Edge | 2015 | Microsoft |
| Safari | 2003 | Apple |
| Opera | 1995 | Opera Software |

**First Web Browser:** WorldWideWeb (1990), developed by Tim Berners-Lee.

## 5. Search Engine

- Software system that searches the WWW and returns results.
- Main processes: Crawling → Indexing → Ranking.

| Search Engine | Year | Key Point |
|---|---:|---|
| Archie | 1990 | First search engine |
| Yahoo! | 1995 | Search engine |
| Google | 1998 | Larry Page & Sergey Brin |
| Baidu | 2000 | China |
| DuckDuckGo | 2008 | Privacy-focused |
| Bing | 2009 | Microsoft |

## 6. Important Internet Terms

| Term | Meaning |
|---|---|
| URL | Uniform Resource Locator — full web address |
| Domain Name | Human-readable website address |
| ISP | Internet Service Provider |
| IP Address | Unique numerical label assigned to a device |
| Downloading | Internet/server → Computer |
| Uploading | Computer → Internet/server |
| Bandwidth | Maximum data transferred over a network in a given time |
| Latency | Time delay in data transmission |
| Cookies | Small files stored in browser |
| Cache | Temporary browser storage for faster loading |
