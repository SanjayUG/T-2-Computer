# Computer Networking

## 1. Networking

Networking is the practice of connecting multiple computers or devices to share resources, exchange data and communicate efficiently.

## 2. Types of Networks

| Type | Full Form | Coverage / Use |
|---|---|---|
| PAN | Personal Area Network | Very small range (1–10 metres); Bluetooth, hotspot |
| LAN | Local Area Network | Home, office, school |
| WLAN | Wireless Local Area Network | LAN using wireless technology; Wi-Fi |
| MAN | Metropolitan Area Network | City or metropolitan area |
| WAN | Wide Area Network | Country or worldwide; Internet |
| SAN | Storage Area Network | High-speed network for storage devices |
| VPN | Virtual Private Network | Secure private network over public internet |

## 3. Data Communication

Exchange of data between devices through transmission media.

| Mode | Direction | Example |
|---|---|---|
| Simplex | One-way only | TV broadcast |
| Half-Duplex | Two-way, one at a time | Walkie-talkie |
| Full-Duplex | Two-way simultaneously | Telephone |

## 4. Network Topologies

Network topology refers to the physical or logical arrangement of devices in a network.

| Topology | Structure | Key Point |
|---|---|---|
| Bus | All devices connected to one backbone cable | Main cable failure affects the whole network |
| Star | Devices connected to a central hub/switch | Central device failure breaks network |
| Ring | Devices connected in a circular form | One node/cable failure can break network |
| Mesh | Every device connected to every other device | Highly reliable but expensive |
| Tree | Combination of star and bus | Scalable and structured |
| Hybrid | Combination of two or more topologies | Flexible but complex |
| Point-to-Point | Direct link between two devices | Simple and fast |

## 5. Networking Devices

| Device | Function |
|---|---|
| Router | Connects networks; forwards packets using IP addresses |
| Switch | Connects LAN devices; forwards data using MAC addresses |
| Hub | Broadcasts data to all connected devices |
| Bridge | Connects LAN segments; filters traffic using MAC |
| Gateway | Connects networks using different protocols |
| Modem | Converts digital signals ↔ analog signals |
| Access Point | Connects wireless devices to a wired LAN |
| Repeater | Amplifies or extends network signals |
| Firewall | Filters network traffic for security |

## 6. OSI Model

OSI (Open Systems Interconnection) is a 7-layer framework that standardizes data transmission over a network.

| Layer | Name | Main Function |
|---|---|---|
| 7 | Application | User interaction and services |
| 6 | Presentation | Data translation, encryption, compression |
| 5 | Session | Establishes, manages and terminates sessions |
| 4 | Transport | Reliable delivery and error checking |
| 3 | Network | Logical addressing and routing |
| 2 | Data Link | Error detection and MAC addressing |
| 1 | Physical | Transmission of raw bits |
