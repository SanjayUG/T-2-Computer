# CPU and Hardware

## Central Processing Unit (CPU)

**CPU = Brain of the Computer**

| Component | Function |
|---|---|
| ALU | Arithmetic and logical operations |
| CU | Controls instructions and data flow |
| Registers | Temporary high-speed storage |

## CPU Speed

Measured in clock cycles per second.

| Unit | Value |
|---|---:|
| Hz | 1 cycle/second |
| kHz | 1,000 Hz |
| MHz | 10⁶ Hz |
| GHz | 10⁹ Hz |

**Example:** 3 GHz = 3 billion cycles per second.

## Important Points

- CPU = Central Processing Unit.
- CPU contains ALU, CU and Registers.
- Intel and AMD are processor manufacturers.
