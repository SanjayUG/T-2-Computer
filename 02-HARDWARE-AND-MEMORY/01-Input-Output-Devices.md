# Input and Output Devices

## Input Devices

| Device | Function |
|---|---|
| Keyboard | Enters text and numbers; QWERTY layout |
| Mouse | Pointing, clicking and scrolling |
| Scanner | Converts documents into digital form |
| OCR | Converts printed text into editable text |
| OMR | Reads marked answers |
| MICR | Reads bank cheques |
| Barcode Reader | Reads barcodes |
| Joystick | Gaming and machine control |
| Light Pen | Selects or draws on screen |
| Microphone | Inputs sound |

## Output Devices

| Device | Function |
|---|---|
| Monitor (VDU) | Displays visual output |
| Projector | Displays output on large screens |
| Plotter | Prints maps and large drawings |
| Speaker | Produces sound |
| Printer | Produces hard copies |

## Types of Printers

| Impact Printers | Non-Impact Printers |
|---|---|
| Dot Matrix | Inkjet |
| Line Printer | Laser |
| Daisy Wheel | Thermal |

- **Impact:** Strikes ribbon against paper; noisy.
- **Non-Impact:** Does not strike paper; quieter.

## Important Points

- Touchscreen → Both input and output.
- OCR → Printed text recognition.
- OMR → Marked answer recognition.
- MICR → Bank cheque recognition.
- Plotter → Large drawings and maps.
