# Computer Memory

Computer memory stores data and instructions for processing.

## Classification of Memory

| Type | Description | Examples |
|---|---|---|
| Primary Memory | Directly accessible by CPU | RAM, ROM |
| Secondary Memory | Permanent storage; slower than primary | HDD, SSD, CD/DVD, Pen Drive |
| Cache Memory | High-speed memory between CPU and RAM | L1, L2, L3 |

## Primary Memory

| RAM | ROM |
|---|---|
| Random Access Memory | Read Only Memory |
| Volatile | Non-volatile |
| Data lost when power is off | Data retained after power off |
| Read and write | Mostly read-only |
| Temporary processing data | Stores firmware (BIOS) |

### Types of RAM

| Type | Key Feature |
|---|---|
| SRAM | Faster, costlier; uses flip-flops; used in cache |
| DRAM | Slower, cheaper; uses capacitors; needs refreshing |
| SDRAM | Synchronized with CPU clock |
| DDR SDRAM | Transfers data twice per clock cycle; DDR1–DDR5 |

### Types of ROM

| Type | Key Feature |
|---|---|
| PROM | Programmed only once |
| EPROM | Erased using UV light |
| EEPROM | Erased and reprogrammed electrically |
| Flash Memory | Block-wise erasing; used in pen drives, SSDs and memory cards |

## Secondary Memory

- Non-volatile; data remains after power-off.
- Larger capacity and slower than primary memory.
- Lower cost per bit.
- Stores OS, programs, applications and user data.

| Category | Devices / Key Points |
|---|---|
| Magnetic | HDD (magnetic platters), Floppy Disk (obsolete) |
| Optical | CD (700 MB), DVD (4.7–17 GB), Blu-ray (25–128 GB) |
| Solid-State | SSD (flash memory, no moving parts), USB Flash Drive, SD/MicroSD |
| Cloud | Google Drive, Dropbox; online storage |

## Important Points

- Cache stores frequently used instructions.
- Cache levels: L1, L2, L3.
- SRAM is used in cache; DRAM is used as main system memory.
- Flash memory is a type of advanced EEPROM.
