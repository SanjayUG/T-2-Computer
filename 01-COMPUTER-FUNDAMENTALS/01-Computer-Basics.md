# COMPUTER FUNDAMENTALS

## 1. Basics of Computer

### 1.1 Definition

A computer is an electronic device that can store, retrieve, and process data to produce meaningful information.

**Important:** 
- Data = Raw facts and figures.
- Information = Processed and meaningful data.

---

### 1.2 Key Features of a Computer

| Feature | Explanation |
|---|---|
| Speed | Performs millions of instructions per second. |
| Accuracy | Produces accurate results if input and instructions are correct. |
| Automation | Executes tasks automatically once programmed. |
| Storage | Stores large amounts of data permanently or temporarily. |
| Versatility | Performs multiple tasks such as calculations, gaming and browsing. |
| Diligence | Never gets tired or loses concentration. |

**Exam Focus:**
- Speed: High processing capability.
- Accuracy: Depends on correct input and instructions.
- Diligence: Ability to work continuously without fatigue.
- Automation: Works according to given instructions.

---

## 2. Basic Operations of a Computer

A computer performs four basic operations:

**Input → Processing → Output → Storage**

| Operation | Function | Examples |
|---|---|---|
| Input | Accepts data and instructions. | Keyboard, Mouse |
| Processing | Processes data according to instructions. | CPU |
| Output | Displays processed information. | Monitor, Printer |
| Storage | Saves data for future use. | HDD, SSD |

### Important Points

- Input Unit: Accepts data and instructions.
- Processing Unit: Performs operations on data.
- Output Unit: Produces meaningful results.
- Storage Unit: Stores data and information.

---

## 3. CPU Speed Measurement

CPU (Central Processing Unit) is known as the **Brain of the Computer**.

CPU speed is measured in clock cycles.

| Unit | Equivalent |
|---|---:|
| Hertz (Hz) | 1 cycle per second |
| Kilohertz (kHz) | 1,000 Hz |
| Megahertz (MHz) | 1 million Hz |
| Gigahertz (GHz) | 1 billion Hz |

### Example

A CPU operating at 3 GHz performs approximately 3 billion clock cycles per second.

**Remember:**

1 GHz = 1,000 MHz

1 MHz = 1,000 kHz

1 kHz = 1,000 Hz

---

## 4. Binary System

- Computers use the binary number system.
- Binary system consists of only two digits: 0 and 1.
- A binary digit is called a Bit.
- 8 Bits = 1 Byte.

| Term | Meaning |
|---|---|
| Bit | Binary Digit |
| Byte | 8 Bits |

**Exam Focus:** Computers fundamentally process data in binary form.
