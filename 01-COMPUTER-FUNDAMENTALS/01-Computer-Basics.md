# COMPUTER BASICS

## 1. Definition

A computer is an electronic device that accepts data, processes it, stores it and produces information.

- Data: Raw facts and figures.
- Information: Processed and meaningful data.

## 2. Characteristics

| Feature | Meaning |
|---|---|
| Speed | Performs millions of operations quickly. |
| Accuracy | Gives accurate results with correct input. |
| Automation | Works automatically after instructions are given. |
| Storage | Stores large amounts of data. |
| Versatility | Performs different types of tasks. |
| Diligence | Works continuously without fatigue. |

## 3. Basic Operations

**Input → Processing → Output → Storage**

| Operation | Function |
|---|---|
| Input | Accepts data and instructions. |
| Processing | Processes data through CPU. |
| Output | Produces results. |
| Storage | Saves data for future use. |

## 4. CPU Speed Units

| Unit | Equivalent |
|---|---:|
| 1 Hz | 1 cycle/second |
| 1 kHz | 1,000 Hz |
| 1 MHz | 10⁶ Hz |
| 1 GHz | 10⁹ Hz |

## 5. Binary System

- Computers use the binary system (0 and 1).
- Bit: Binary Digit; smallest unit of data.
- 1 Byte = 8 Bits.
