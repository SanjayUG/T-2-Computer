# Computer Architecture

## Basic Functional Units

| Unit | Function |
|---|---|
| Input Unit | Accepts data and instructions |
| CPU | Processes data and controls operations |
| Memory Unit | Stores data, instructions and results |
| Output Unit | Displays processed results |
| Storage Unit | Stores data for long-term use |

## Central Processing Unit (CPU)

**CPU = Brain of the Computer**

| Component | Function |
|---|---|
| Control Unit (CU) | Controls data flow and coordinates operations |
| Arithmetic Logic Unit (ALU) | Performs arithmetic and logical operations |
| Registers | High-speed temporary storage inside CPU |

## Working Flow

**Input → CPU Processing ↔ Memory → Output**

**Storage Unit:** Retains data for future use.
